# Ulearn-Helper

优学院（Ulearning）Tampermonkey 脚本，提供课程进度工作台、视频与章节练习辅助、作业／考试查题，以及可配置的 AI 答题与控件填写。

当前脚本：**v4.18.3** · [安装脚本](https://raw.githubusercontent.com/ghost0190/Ulearn-Helper/main/Ulearn-Helper.user.js) · [反馈问题](https://github.com/ghost0190/Ulearn-Helper/issues)

## 安装与更新

### 首次安装

1. 在 Edge 或 Chrome 中安装 Tampermonkey，并按扩展提示允许用户脚本运行。
2. 打开上方“安装脚本”链接，在 Tampermonkey 确认页点击安装。
3. 刷新优学院课程、作业或考试页面，打开悬浮窗中的设置。

浏览器直连 AI、本地题库和远程静态题库均可直接随脚本使用，无需运行后端、浏览器插件连接服务或 MCP。

### 已有用户更新

在 Tampermonkey 管理面板中，对**原脚本记录**执行“检查更新”，安装后刷新页面。原脚本记录上的更新会沿用已保存的配置和密钥。

v4.18.1 将安装名称统一为 Ulearn-Helper。如果仍显示旧名称，优先通过原记录更新；直接重新安装可能产生第二份脚本。确认同一页面只启用一份。

| 更新方式 | 行为 |
| --- | --- |
| Tampermonkey 自动更新 | 根据脚本的 `@updateURL` 与 `@downloadURL` 更新；频率及自动安装开关由扩展设置控制 |
| 脚本启动检查 | 每 6 小时最多检查一次公开版本元数据；失败后冷却 30 分钟，发现新版在悬浮窗提示 |
| 设置 → 关于 → 检查更新 | 手动检查，并提供新版本安装入口；启动检查可在这里关闭 |

脚本中的版本检查只提示更新，不会直接替换正在运行的代码。GitHub 无法访问时，已安装的脚本仍可使用。

## 开始使用

1. **设置 → AI 接口**：添加接口，选择服务商预设，填写 API 地址、API Key 和模型。自定义接口也可手动配置。
2. 点击“拉取模型列表”或直接输入模型 ID，再用“测试这个 AI”检查连接。界面的参考候选不代表当前账号有调用权限。
3. **设置 → 来源**：启用需要的来源并调整顺序。默认开启本地缓存优先；未命中时按启用来源的顺序查询。
4. 在课件页查看学习工作台；在作业／考试页使用答题工具。先确认识别出的题目、答案与填写结果，再进行页面上的提交操作。

密钥只需保存一次。输入框显示“已保存”且为空是正常行为；输入新值可替换，点击“清除”可删除。更换浏览器配置文件或移除脚本存储后，需要重新配置。

## 功能

| 场景 | 功能 |
| --- | --- |
| 课程进度 | 课件页默认展示学习工作台，显示平台返回的进度、进度条、运行中任务和已完成目录；可返回原课件 |
| 课程导航 | 根据目录与完成记录定位未完成项目，跳过已完成页面；课程结束后停止运行 |
| 视频处理 | 自动播放、倍速、静音，以及完成状态保存和服务器读回核对；优先提交状态失败后重试并回退播放 |
| 章节练习 | 识别练习与综合题子题；填写后确认平台完成状态，再决定是否跳转 |
| 作业／考试 | 查题与填写，支持单选、多选、判断、填空、简答和翻译等已适配结构 |
| 英语选词填空 | 识别原生下拉及常见弹出候选列表，按空位顺序读取候选、解析答案并核对选中结果 |
| 悬浮窗 | 拖动位置、调整大小、最小化；题目与答案可展开／收起，点击正文复制完整内容 |

课程页和作业／考试页分别展示对应工具。视频完成与进度以服务器读回结果为准；生成的观看区间记录不代表实际观看过程。纯视频页的处理方式不会直接套用于混合练习页。

### AI 答题与操作兜底

- 请求包含完整题干、题型、单选／多选标记、有序选项、材料、补充信息，以及填空数量和逐空候选。
- 按统一 JSON 协议解析答案；不确定、空数不符、选项越界或格式不完整的结果不当作有效答案保存。
- 批量请求按题号区分答案，并按题数和提示词长度分批；批量预取遵守来源优先级。
- 考试普通填写失败后，可由 AI 操作当前题目的已知控件，最多额外请求两轮，并验证实际填写结果。可在“来源”页关闭。

操作兜底是脚本内置的 DOM 控件代理，**不是 Playwright/MCP**。它仅应用已知答案，不能替代真实用户输入、跨域页面或画布控件，也不会通过该代理自动交卷。

## 设置说明

| 设置页 | 可配置内容 |
| --- | --- |
| 来源 | 查询顺序、来源启停、轮询兜底、本地缓存优先、批量提问、AI 间隔与并发，以及学习和控件代理开关 |
| AI 接口 | 添加、重命名、删除、启停接口；服务商预设、模型搜索／拉取、连接测试及高级请求参数 |
| 题库 | 本地题库导入／导出、远程静态题库地址与同步 |
| 服务器 | 可选后端地址、Token 与连接检查 |
| 关于 | 主题、题目／答案预览字数、诊断报告及脚本更新 |

默认题目预览为 **80 字**、答案预览为 **120 字**；调整后重新查询生效。AI 默认最大并发为 **2**，可调为 **1–4**，默认请求启动间隔为 **1,000 毫秒**。并发不会缩短单次模型生成时间；出现 429 时可降低并发、增大间隔，并核对服务商额度。

AI 高级配置支持自定义鉴权方式、额外请求头、请求体模板、输出取值路径和模型列表地址。切换预设会修改地址、模型及鉴权方式，保留已有 Key；切换服务商后应核对 Key 是否属于对应账号。

## 题库与可选后端

| 来源 | 使用方式 |
| --- | --- |
| 本地题库 | 保存在脚本存储中，可导入／导出；默认优先读取已有缓存 |
| 远程静态题库 | 配置可访问的 JSON 地址，下载后合并至本地；无需后端 Token |
| 自建后端 | 配置服务地址与 Token，由服务器提供题库查询及可选 AI 兜底 |

导入可使用 `{ "answers": [...] }`、答案数组或兼容的本地 `map` 格式。记录应保留题型、选项、材料、填空结构及多选标记；题干相同并不意味着答案可以通用。多选记录示例：

```json
{
  "answers": [
    {
      "title": "请选择符合条件的选项",
      "kind": "choice",
      "multiple": true,
      "options": ["Alpha", "Beta", "Gamma"],
      "answer": "Alpha||Beta"
    }
  ]
}
```

**本公开仓库目前只分发脚本、更新元数据和 README，不包含后端及完整开发测试文件。** 自建后端是可选的独立组件；已有完整项目的用户可更新关联后端至 **2.5.0** 并重启。后端使用 Node.js 内置 SQLite 与 fetch，要求 Node.js ≥ 22.13。

后端默认地址为 `http://127.0.0.1:8787`。首次启动生成的 `credentials.json` 中，`api_token` 用于脚本，`admin_key` 用于管理登录；不要将管理密钥填入脚本。服务器端 AI Key 单独配置，脚本更新不会替换服务器文件。

2.5.0 会在身份迁移前备份题库，区分单选与多选并保留导出标记。无法确定单／多选身份的旧选择题记录标为 `legacyUnknown`，保留供人工核对，前端导入会跳过；补全真实题型和标记、移除该标记后可重新导入。历史已被覆盖的答案不能自动恢复。

## 数据与权限

- AI Key、后端 Token 和配置保存在 Tampermonkey 脚本存储中；已保存的密钥不回填到设置页输入框。
- 使用 AI 时，题目信息会发送给所选 AI 接口；使用自建后端时，查询信息和 Token 会发送给该后端。
- 更新检查只匿名获取公开版本元数据，不发送题目、密钥或账号配置。
- 生产脚本的页面调试接口只公开只读版本信息，不提供读取密钥、修改持久配置或发起 AI 请求的函数。

设置表单位于课程网页；新密钥输入过程中仍属于网页表单数据，不能将其视为独立扩展页面的安全隔离。

## 常见问题

**保存后 Key 输入框为空，是否丢失？**

没有。显示“已保存”表示凭证仍在脚本存储中。可通过连接测试确认，不必每次输入。

**为什么 AI 有答案却没有填进去？**

答案解析与控件填写分别核对。只读、禁用或尚未适配的控件可能无法填写；脚本不会把控件状态未改变报告为成功。检查逐题提示，必要时手动填写。

**为什么课程停在练习页？**

仅填写完成不足以证明平台已保存。没有提交入口或无法确认完成状态时，脚本会等待平台确认；核对页面提示和实际保存结果。

**接口诊断显示 401／403／429 怎么处理？**

401／403 对应凭证或权限问题；429 通常对应限流或额度限制。核对接口地址、账号权限、模型权限与额度，再调整请求间隔和并发。

**为什么更新后界面没有变化？**

检查 Tampermonkey 中实际安装版本，确认只启用一份脚本，再刷新页面。GitHub 访问失败或扩展缓存可能延迟更新。

反馈时请说明脚本版本、页面类型、操作步骤和错误提示。截图或诊断内容中的密钥、Token、个人信息应先隐藏。

- 综合题按可作答的子题识别，排除整组题的外层容器和独立文章展示块；单题查询与批量预取使用同一套读题逻辑。
