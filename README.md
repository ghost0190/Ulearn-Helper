# Ulearn-Helper

优学院 Tampermonkey 脚本，当前版本 **4.18.2**。

## 安装与更新

1. 在 Edge/Chrome 安装 Tampermonkey 并允许用户脚本运行。
2. [安装 Ulearn-Helper](https://raw.githubusercontent.com/ghost0190/Ulearn-Helper/main/Ulearn-Helper.user.js)。已有版本请在 Tampermonkey 管理面板中对原脚本执行“检查更新”。4.18.1 将安装名称统一为 Ulearn-Helper；在原脚本记录上更新可保留已有配置。改名时直接打开安装链接可能产生第二份脚本。
3. 刷新课程或考试页面加载新版。

Tampermonkey 根据脚本的 updateURL 与 downloadURL 自动检测和安装更新；检查频率及自动更新开关由扩展设置决定。脚本启动时最多每 6 小时获取一次版本元数据，失败后 30 分钟可再试；发现新版会在悬浮窗版本按钮提示，点击进入安装页。设置 → 关于可手动检查、关闭启动检查及打开仓库。启动检查不直接替换运行中的脚本。

## 功能与设置

- 课程与考试/作业页面分别显示学习和答题工具。课件页默认打开学习进度工作台，展示平台确认的进度、当前任务与已完成目录；可返回原课件并通过“学习面板”重新打开。目录记录最多两路并发读取，不通过逐页跳转收集进度。
- 考试普通填写重试失败后，使用已配置的 AI 接口操作当前题目的已知控件，最多额外请求两轮；填写值与已知答案逐项核对，不自动交卷。设置 → 来源可关闭。操作仅支持页面允许的 DOM 事件，无法替代需要真实用户输入、跨域或画布控件的操作。
- AI 接口可添加、重命名、删除、启停；名称校验、单步撤销、模型搜索和服务商文档入口。
- AI 请求采用有限并发和取消保护；题目及答案支持折叠，悬浮窗可拖动调整尺寸。
- 本地题库、远程题库与自建服务端均为可选来源。

接口密钥和用户配置由 Tampermonkey 保存在本机，公开仓库不包含浏览器连接令牌、个人密钥、题库或课程抓取记录。更新检查仅下载公开版本元数据。GitHub 不可达时检查会显示失败，已安装的功能继续运行。

## 维护发布

默认发布分支为 main。修改 Ulearn-Helper.user.js 并递增 @version；将其完整元数据头同步到 Ulearn-Helper.meta.js，然后把两个文件在同一提交中发布。安装名称统一为 Ulearn-Helper；保持 @namespace 和下载地址稳定。涉及改名时，通过原脚本记录更新，并核对配置是否沿用。发布前执行 node --check Ulearn-Helper.user.js 并验证两个文件的 @version 一致。

后续版本必须同步更新脚本和元数据，不能只修改仓库标签。用户更新周期取决于扩展设置、缓存与网络；不会即时强制更新。

## 4.18.2 修复

- 页面调试接口仅保留只读版本信息；设置页不回填已保存的 Key/Token，输入新值替换，也可清除。
- 被拦截 XHR 正确完成，支持取消、复用及响应类型，避免挂起和旧响应残留。
- 配置使用字段合并与独立存储记录，避免不同标签页整体回写覆盖密钥；撤销只还原本次编辑。
- 批量 AI 预取遵守来源顺序；自动收录保留题型与选项；待补题与答案使用统一容量限制。
- 自定义接口及模型列表保留 URL 查询参数；401/403/429 诊断按实际状态解释。
- 关联后端 2.5.0 区分单选、多选，导出保留标记，并拒绝非 2xx AI 响应。后端需单独升级部署，油猴更新不会替换服务器。

已保存的密钥继续有效，不需要每次输入。历史后端选择题若已丢失单选/多选标记，会先备份再隔离，需补充真实题型后重新导入；此前已覆盖的答案不能自动恢复。
